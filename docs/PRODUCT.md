# VideoPlayer 产品说明书

## 一、产品概述

一款运行在 **Windows** 的本地视频播放器，定位为「大规模本地视频库的浏览 + 播放工具」。三个核心价值：

1. **解码能力强** —— 依托 mpv（内置 FFmpeg），几乎不挑格式，支持硬件解码
2. **海量导入与智能分类** —— 导入文件夹后自动把子目录扁平化为分类标签，同时保留原始目录树
3. **高效浏览与键盘操控** —— 瀑布流卡片 + 缩略图，支持纯键盘方向键（含对角组合键）导航

---

## 二、页面结构

产品主要由两个页面组成：**主页面（列表页）** 与 **全屏播放页**。

### 2.1 主页面

自上而下分为「顶部工具区」与「视频列表区」。

#### 顶部工具区

- **导入入口**：选择一个或多个文件夹导入（支持拖拽），递归扫描其下所有视频文件
- **分类标签栏（扁平化）**：导入后自动把所有子文件夹名去重生成标签 tag
  - 支持多选，多个 tag 之间可切 OR / AND 逻辑（默认 OR）
  - 选中标签即实时过滤视频列表
- **原始目录树视图**：可切换到树形模式，展示完整目录拓扑结构，点击任意节点按该目录（含子目录）过滤
- **随机播放**：「打乱」按钮打乱当前过滤结果的顺序，可反复点击重新洗牌
- **主题切换**：一键在三套主题间切换（详见第五节）
- **全屏模式设置**：切换三种全屏播放方式（详见 2.2）

#### 视频列表区

- **瀑布流布局**：根据视频宽高比，自动分为横向卡片（宽高比 > 1）与竖向卡片（< 1）
- **卡片内容**：缩略图、文件名、时长、分辨率角标
- **缩略图**：导入时后台用 FFmpeg 抽取关键帧生成，缓存复用
- **虚拟滚动**：只渲染可视区，支撑海量视频不卡顿
- **选中方式**：
  - 鼠标悬浮高亮
  - 键盘方向键 ↑↓←→ 移动焦点
  - **对角组合键**：同时按两个方向键（如 → + ↑）取合方向移动
- **打开播放**：鼠标单击或键盘回车键 → 进入全屏播放

### 2.2 全屏播放页

三种全屏模式（顶部设置中切换）：

| 模式 | 说明 | 备注 |
|---|---|---|
| App 页面内全屏 | 播放器覆盖整个 Electron 窗口，窗口大小不变 | 依赖 mpv 嵌入（Windows `--wid`） |
| 窗口桌面全屏 | Electron 窗口进入操作系统全屏 | 依赖 mpv 嵌入 |
| 独立桌面全屏 | 独立 mpv 窗口直接桌面全屏，性能最佳 | 当前已实现的模式 |

**播放控件**：播放/暂停、进度条（拖拽 + 预览缩略图）、音量、倍速（0.5x–4x）、时间显示、字幕/音轨切换（有则显示）。

**交互约定**：
- **再次按回车 → 返回列表页**（已实现）
- `Esc` 退出全屏
- 空格 暂停/播放
- ←→ 快进/快退
- ↑↓ 音量增减

## 三、功能规格

### 3.1 导入与分类

- 导入一个或多个文件夹，递归遍历目录树，按扩展名过滤视频文件（mp4/mkv/avi/mov/flv/wmv/ts/webm 等）
- 扁平化标签：导入路径下所有子文件夹名去重生成 tag。例如导入 `D:\Movies`，其下有 `动作/`、`喜剧/2023/`，则生成 `动作`、`喜剧`、`2023` 等标签
- 标签多选过滤，支持 OR / AND
- 原始目录树保留完整拓扑，可按目录过滤
- 增量导入：重复导入或重扫时只处理新增/变动文件（按路径 + 修改时间判断）

### 3.2 缩略图与元数据

- 导入时后台任务队列逐个用 FFmpeg 抽帧（默认取时长 10% 处一帧，避开黑屏片头）
- 读取分辨率 → 计算宽高比 → 决定卡片横向或竖向
- 缩略图缓存为 webp，存到 appData/thumbnails/，数据库记录路径
- worker 线程池并发生成，控制并发避免卡顿，带进度条

### 3.3 随机播放

- 「打乱」作用于当前过滤后的结果集，可反复点击重新洗牌
- 可选：随机连播模式（一个播完自动下一个）

### 3.4 键盘空间导航

- 方向键在不规则瀑布流中移动焦点
- 对角组合键：同时按两个方向键取合方向
- 算法：维护当前焦点卡片几何中心，对候选卡片按「方向夹角 + 距离」打分，选最优目标
- 焦点卡片高亮并自动滚动到可视区

## 四、数据模型（SQLite）

```
videos     (id, path, name, ext, size, duration, width, height,
            aspect_ratio, thumbnail_path, folder_id, added_at, mtime)
folders    (id, path, name, parent_id, import_root_id)  -- 原始目录树
tags       (id, name)                                    -- 扁平化标签
video_tags (video_id, tag_id)                            -- 多对多
settings   (key, value)                                  -- 主题/全屏模式/偏好
```

## 五、主题设计

CSS 变量驱动，三套主题一键切换并持久化：

- **白天**：浅色、高对比、清爽
- **夜间**：深灰/纯黑，护眼
- **浪漫情趣风**：暖色 + 紫红/粉渐变、柔光模糊、圆角与光晕，营造氛围感

---

## 六、非功能需求

- **性能**：海量视频（1000+）下列表滚动流畅，靠虚拟滚动 + 缩略图缓存 + 数据库索引三管齐下
- **重活隔离**：扫描、抽帧、解码全部放主进程/独立进程，渲染进程只管 UI
- **持久化**：主题、全屏模式、播放偏好等写入 settings 表
